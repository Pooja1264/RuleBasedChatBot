# Rule-Based AI Chatbot

## Description
This is a simple rule-based chatbot developed using Python.

## Features
- Greeting responses
- AI and Python information
- Date and Time
- Calculator
- Random jokes
- Motivational quotes
- Exit command

## Technologies Used
- Python 3.12
- VS Code

## How to Run

```bash
python chatbot.py
```
